# OWASP Juice Shop Setup & Testing

## Project Overview
This project demonstrates the setup, reconnaissance, and exploitation of multiple vulnerabilities in the OWASP Juice Shop application.

## Vulnerabilities Covered
- SQL Injection Authentication Bypass
- DOM-based Cross-Site Scripting (XSS)
- Broken Access Control
- Insecure Direct Object Reference (IDOR)
- Forged Feedback / Improper Authorization

## Tools Used
- Nmap
- Dirb
- Burp Suite
- OWASP Juice Shop
